# DocInspector v0.3.1 · 桌面正式发布

> 轻量、离线、可追溯的本地文档与代码关键词检查工具。

面向 Ubuntu amd64 和 Windows x64 提供可直接安装的发布包。

## 本版亮点

- **自定义检查方案**：支持禁止词、必须词、搜索词，自定义名称、编辑、复制与删除。
- **一键批量扫描**：支持文件夹递归、多个文件和常见代码文件。
- **Rust 高效匹配**：Aho–Corasick 多关键词一次匹配，支持重叠命中，最多四个工作线程。
- **匹配选项**：区分大小写、完整单词匹配、跳过缓存目录、自定义排除目录。
- **结果操作**：关键词高亮、结果内筛选、拖动分栏、双击打开原文件、CSV 导出。
- **历史留存**：按方案保存扫描历史，可以重新打开检查证据。
- **本地只读**：文件不上传云端，也不会被扫描操作修改。

## 安装

| 平台 | Release Asset | 安装方式 |
| --- | --- | --- |
| Ubuntu / amd64 | DEB 安装包 | 下载 .deb 后通过 apt 安装 |
| Windows 10/11 / x64 | NSIS 安装器 | 下载 -setup.exe 后双击 |

在此页面下方的 **Assets** 直接下载对应安装包，无须再去 Actions 下载压缩 Artifact。

## 已知边界

- 关闭区分大小写仅忽略 ASCII 英文大小写；未实现完整 Unicode 折叠。
- 图片 PDF 尚不支持 OCR；复杂 Office 嵌入对象可能无法覆盖。
- 命中证据数量有存储上限，完整留档建议扫描完成后导出 CSV。
- Android 仅提供独立预览构建，不属于本次桌面正式 Release。

## 质量验证

Linux、Windows 安装包来自同一次 GitHub Actions 构建，打包前运行 Rust 单元测试。实际桌面交互仍欢迎用户提供反馈。
