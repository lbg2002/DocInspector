# DocInspector v0.3.2 · 界面焕新与文档解析增强版

> 轻量、离线、可追溯的本地文档与代码关键词合规检查工具。

面向 Ubuntu amd64 和 Windows x64 提供可直接安装的桌面发布包。

## 本版更新亮点

- **工作台视觉与交互全面升级**：
  - 支持 **深色星夜 / 浅色纸感** 双主题一键切换，适配不同办公与审阅环境。
  - 侧边栏新增顶层导航（检查工作台、扫描结果实时状态徽标、规则配置、设置与迁移），在各页面间自由切换不丢失当前扫描结果。
  - 工作台直接展示当前方案的 **规则标签云**（禁止 / 必需 / 检索分类筛选、单击快速启停规则、内联快速补充关键词）。
  - 支持将文件或文件夹 **直接拖入窗口** 添加为扫描来源。
- **内置常用方案模板库**：
  - 提供「论文终稿检查」「敏感与内部信息排查」「代码调试与待办清理」「合同与公文规范核查」4 套预设模板，支持一键新建或导入至现有方案。
  - 方案编辑器支持 8 色标识色选择、规则分类筛选、关键词搜索及批量启用/停用。
- **结果审查工作台体验提升**：
  - 顶部 4 张统计卡片支持点击直接联动筛选对应状态文件，并新增 **「↑ 上一问题 / ↓ 下一问题」** 快捷定位与 **复制 Markdown 检查摘要**。
  - 左侧文件列表新增排序切换（问题优先 / 按命中数 / 按文件名）及违规/缺失微章统计。
  - 右侧证据详情支持按规则类型与单个命中词二次过滤、同一片段内多处命中词精准高亮，以及单条上下文一键复制。
- **底层文档解析与编码兼容增强**：
  - **Word / PPT 精细化定位**：DOCX 支持正文、页眉、页脚、脚注、尾注、批注并精确到段落号（如 `正文 · 第 2 段`、`批注 · 第 1 段`）；PPTX 按页序排列幻灯片与演讲者备注并精确到段落号（如 `第 3 页幻灯片 · 第 1 段`）。
  - **中文编码自适应**：纯文本与代码文件除 UTF-8 外，自动兼容 UTF-8 BOM、UTF-16LE/BE 及 GB18030/GBK 中文编码。
  - **CSV 导出优化**：自动附带 UTF-8 BOM，使用 Excel / WPS 直接双击打开不乱码。

## 安装方式

| 平台 | Release Asset | 安装方式 |
| --- | --- | --- |
| Ubuntu / amd64 | DEB 安装包 | 下载 `.deb` 后执行 `sudo apt install ./*.deb` |
| Windows 10/11 / x64 | NSIS 安装器 | 下载 `-setup.exe` 后双击安装 |
